Entrants write a single status page line, at most 160 characters, as the message an AI agent would publish while a total server outage is under way. It has to read like a real status page: plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know. A judge model compares the lines two at a time on honesty, status page voice, admitted uncertainty and tight wording, and the most honest line takes the pool.

## Run it

```sh
python3 main.py
```
